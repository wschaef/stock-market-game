# stock-market-game

Prototype of a game to learn the stock market (Börsenspiel hotseat).

Rules: [docs/game-rules.md](docs/game-rules.md) (digital rulings are authoritative).

```bash
npm install
npm test
npm run dev
```

Build for GitHub Pages: `npm run build` (static `dist/`, relative `base`). Deploy job: `.github/workflows/pages.yml`.
