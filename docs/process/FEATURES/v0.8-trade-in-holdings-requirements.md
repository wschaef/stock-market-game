# Feature requirements: v0.8-trade-in-holdings

**Status:** agreed  
**Owner:** Waldemar  
**Date:** 2026-10-01  

## Goal

Put **Buy / Sell** stock controls inside the **Holdings** panel on the **on-turn player row** so traders act next to their share counts, and remove the separate Trade strip panel.

## In scope

- During a human trade phase (`optionalTrade`), Buy and Sell appear in the **on-turn seat’s company cells** (under that seat’s share count)
- Quantity input and **End turn** stay in a toolbar inside Holdings while trading
- Remove the standalone Trade strip panel from the board layout
- Desktop and mobile use the same integrated layout (CSS only if needed for density)

## Out of scope

- Rules / engine / AI trade logic
- Changing when trade is allowed
- Redesign of holdings table data (player rows, prices, market totals, wealth preview) beyond trade chrome
- New networking or persistence

## Users / context

Hotseat human on trade: they already look at Holdings for prices and counts; Buy/Sell should sit on their on-turn row instead of a second panel below.

## Functional requirements

1. When it is a human’s `optionalTrade` phase, the **on-turn player row** shows **Buy** above and **Sell** below each company share count.
2. Quantity (shared across companies) and **End turn** remain available in a Holdings toolbar while trading.
3. Outside a human trade phase, Holdings looks as today (no trade chrome).
4. The separate **Trade** strip panel is gone; no duplicate Buy/Sell elsewhere on the board.
5. Buy / Sell / End turn / quantity behavior and validation unchanged (same intents as today).
6. Narrow and wide viewports both keep trade controls usable without a second trade panel.

## Non-functional requirements

- UI-only change; no engine API changes
- Prefer extending `Scoreboard` / Holdings markup + CSS over a forked mobile tree
- Respect existing motion / reduced-motion patterns
- Compact controls so four company columns stay usable on narrow viewports

## Acceptance checklist

Human reviews these outcomes (not code by default):

- [ ] During human trade, Buy sits above and Sell below each on-turn company count
- [ ] Quantity + End turn are available in Holdings while trading
- [ ] No separate Trade strip panel remains on the board
- [ ] Outside trade, Holdings has no Buy/Sell chrome
- [ ] Trade rules unchanged (engine tests still pass)
- [ ] Lint/tests relevant to the change are green
- [ ] Demo via `npm run dev` (narrow + wide if easy)

## Open questions
