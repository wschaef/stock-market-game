# Implementation plan: v0.6-ai-play-cards-bugfix

**Status:** done (verified 2026-08-30)

**Date:** 2026-08-26  

## Summary

AI never drew/played because Draw scoring from `chooseTurn` called `reduce(playCard)` while still in `chooseTurn`, so every sim failed and Draw collapsed to standing wealth. Trade kept full hand option value and always won. Fix phase-lifted lookahead, scale share-lead chance so option value does not drown realization, and force Draw when best play wealth beats the trade-plan wealth.

## Approach

1. In `scoreCardPlay` lookahead, if `phase === "chooseTurn"`, clone and set `phase` to `chooseHandCard` before `playCard`.
2. Scale share-lead chance to `0.3 * max(0, s − r) * U` (same order as holding synergy) so unrealized U does not outscore realizing Δprice.
3. Choose-turn wealth override: if best hand-play net worth `>` trade-plan net worth and `>` current wealth → `{ type: "draw" }`.
4. **Second pass:** prefer Draw when `simulateTradePlan` does not deploy cash (empty trade loop); only prefer Trade for idle-cash deploy when the plan actually buys/sells and beats draw score.
5. TDD regressions in `ai.test.ts`; keep idle-cash Trade fixture.
