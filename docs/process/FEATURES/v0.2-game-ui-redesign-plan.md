# Implementation plan: v0.2-game-ui-redesign

**Status:** approved  
**Requirements:** `docs/process/FEATURES/v0.2-game-ui-redesign-requirements.md` (agreed)  
**Date:** 2026-08-16  

## Summary

Redesign the hotseat React UI into a two-column game board (market + scoreboard) with icon-led companies, multi-row card faces from `card.ops`, and a pure wealth-preview helper used on hand-card hover/focus. Engine rules stay unchanged; only presentation and pure UI/engine-adjacent helpers are added.

## Approach

- **No rules changes:** reuse `reduce`, `netWorth`, `applyCompanyTarget`, `allowedChoices`.
- **Pure preview module (TDD first):** given `GameState` + `Card` (+ optional choice company or strategy), return per-player `{ before, after, delta }` wealth. Internally simulate price/share outcomes without mutating live state (clone or functional apply).
- **Card rows from ops:** map each `CardOp` to a display row (`magnitude`/`factor` + company icon or `[?]`). Stop relying on title string layout for the face.
- **Icons:** small inline SVG (or CSS) monograms per company; shared `CompanyMark` component with accessible name.
- **Layout:** CSS grid board shell; scoreboard always lists all players; remove per-bar owner text dumps; restyle surfaces toward tabletop, not stacked admin cards.
- **Open question defaults if human does not override:** (1A) min–max Δ for `[?]` cards; (2) risk as four-icon delta strip; (3) holdings only on scoreboard.

## Steps

1. Agree requirements (resolve open questions) → mark requirements **agreed**.
2. TDD: `previewCardWealth` (and helpers) for named-only cards, choice cards (per agreed strategy), split/wipeout side effects.
3. TDD/light tests for `cardEffectRows(card)` display mapping if non-trivial.
4. Add `CompanyMark` + wire into market, scoreboard, picker, card rows.
5. Rebuild `App.tsx` layout: market | scoreboard, turn actions, hand with hover/focus preview binding into scoreboard diffs.
6. Restyle `index.css` for game-board composition + motion (respect reduced motion).
7. Run lint/tests; prepare demo notes / optional screen capture.

## Out of scope for this plan

- Engine API changes beyond exporting existing helpers if needed
- Trademark logos, networking, persistence

## Risks / notes

- Preview must mirror `applyCompanyTarget` exactly or players will mistrust the UI — reuse engine price application, do not reimplement split/wipeout math in the UI.
- Hover on touch devices needs a non-hover path (focus / press).
- Dense risk cards: keep legible on mobile (scroll OK; no tiny Excel grids).
