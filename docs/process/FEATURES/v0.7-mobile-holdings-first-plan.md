# Implementation plan: v0.7-mobile-holdings-first

**Status:** approved  
**Requirements:** `docs/process/FEATURES/v0.7-mobile-holdings-first-requirements.md` (**agreed**)  
**Date:** 2026-09-26  

## Summary

Restructure the in-game board presentation so narrow viewports lead with a dense **all-players holdings grid + prices**, dock phase actions, and put the **hand in a bottom flyout** (auto-open when the human must play). Wide viewports keep the same components with hand always visible. No engine or rules changes.

## Approach

- **One tree:** keep `Board` / `Scoreboard` / `MarketDiagram` / `Hand` / actions; add layout wrappers and CSS, not parallel boards.
- **Holdings-first:** restyle scoreboard into a compact table (player × company counts + wealth); on narrow, place it above market chrome; add a single **price strip** (four numbers + icons) so prices stay visible without four tall bar rows as the only path.
- **Market secondary on narrow:** keep existing bar market available but collapsed by default on narrow (e.g. `<details>` “Price chart”) or visually de-emphasized under the price strip — YAGNI: prefer `<details>` reuse of current `MarketDiagram` body over a second market implementation.
- **Flyout:** wrap `Hand` in a dock; state `handOpen`. Pure helper `handFlyoutForcedOpen(phase, humanTurn)` → true when `chooseHandCard` + human. Effect or derived open: forced open when helper says so; otherwise user toggles. Wide breakpoint: CSS forces panel in-flow (ignore closed state visually).
- **Preview:** keep binding preview Δ into scoreboard/holdings rows; ensure flyout open still leaves holdings visible (sheet max-height ~50vh, not full screen).
- **Last-drawn / log:** leave as secondary below; optional one-line last-drawn tighten only if needed for acceptance — not a new feature.

## Steps

1. TDD: `handFlyoutForcedOpen` (and any open-state derivation helper if extracted).
2. Refactor scoreboard markup/CSS toward dense holdings table usable on both breakpoints.
3. Add narrow price strip (from existing prices / `CompanyMark`); wrap full bar market in collapsible on narrow only (CSS + minimal markup).
4. Wire hand dock + `handOpen` / forced-open; sticky phase actions with dock on narrow.
5. Reorder / media-query layout in `index.css` (~860px): holdings + prices first; market details collapsed; hand sheet; desktop unchanged in spirit.
6. Run lint/tests; verify narrow + wide manually; short results notes.
