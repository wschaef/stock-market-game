# Feature requirements: v0.3-ai-opponents

**Status:** agreed  
**Owner:** Waldemar  
**Date:** 2026-08-16  

## Goal

Extend Börsenspiel so games run for a configurable number of **rounds** with **recycled** played cards, and so any seat can be a **deterministic** (non-LLM) AI using one of three strategies chosen at setup. Humans can follow AI play via a collapsible action log.

## In scope

- Setup: per seat — human vs AI, and if AI which strategy
- Setup: **rounds** parameter (game length)
- Rule change: after a card is played, insert it at a **random position** in the remaining draw pile; next draw is from that pile
- Game end after N **full table cycles** (each seat one turn = 1 round)
- Three deterministic AI strategies (no LLM)
- AI may use the **same legal actions** as a human (including multiple buys/sells in a trade phase)
- Short **lookahead** when scoring candidate moves (bounded; see decisions)
- Auto-play on AI seats; pacing may vary with decision complexity
- Collapsible **action log** at the bottom of the UI so humans can see what happened
- Engine tests for recycle, rounds end, and strategy decision contracts

## Out of scope

- Online multiplayer, accounts, persistence
- LLM / ML / learned policies
- Difficulty levels beyond the three strategies
- Peeking at face-down draw order for AI evaluation (AI must not cheat on hidden cards)
- Changing the card catalog, split/wipeout math, or starting cash/hand sizes

## Users / context

Hotseat players who want solo practice or mixed human/AI games on one device, with predictable AI behavior and a readable trail of AI (and human) actions.

## Decisions (locked)

| Topic | Decision |
| --- | --- |
| Round | One **round** = every seat has taken one turn (full table cycle). Game lasts **N** rounds. |
| Rounds bounds | **Default 10**, **min 1**, **max 50** |
| Recycle | After play, **insert the card at a random index** in the remaining draw pile (no dead discard). Starting-hand Actions and Risks recycle the same way. |
| Lookahead | **Yes** — score candidates with bounded next-step evaluation (immediate outcome + best follow-up where the phase allows, e.g. trade planning). No peeking at draw order. |
| AI action space | Same intents/phases as human |
| Visibility | Collapsible **log trail** at bottom of UI; AI auto-play paced enough that humans can follow (delay may scale lightly with complexity) |
| Strategy ids / labels | `wealth` → **Investor**; `punish` → **Raider**; `balanced` → **Mixed** |

## Functional requirements

### Setup

1. Keep 2–4 seats. Each seat: name, **controller** (`human` \| `ai`), and if AI a **strategy** (`wealth` \| `punish` \| `balanced`).
2. **Rounds** integer: default 10, min 1, max 50.
3. Allow all-AI and mixed human/AI games (still 2–4 seats).

### Card recycle & game length

4. When a card is **played** (Action from hand or Risk resolved from draw), insert it at a **random position** in the current draw pile. Do not leave played cards in a permanent discard that never returns.
5. Track `roundsTotal` and `roundsCompleted` (or equivalent). After a seat finishes their turn, if that seat was the last in the cycle for the current round, increment completed rounds. When `roundsCompleted === roundsTotal` after that turn fully resolves (including optional post-Risk trade), `phase = gameOver`.
6. Ranking unchanged: `cash + Σ(shares × price)`.

### AI (deterministic)

7. When the current seat is AI and a decision is required, select intents via a pure function of `(state, seatConfig, strategy)` plus seeded RNG only where the rules require randomness (e.g. recycle insert). **No LLM.**
8. Cover every decision: Draw vs Trade-only; hand card; `[?]` company; buy / sell / endTrade (multiple trades allowed, same rules as human).
9. **Investor (`wealth`):** maximize own net worth under the lookahead scorer; ties → maximize lead over the best rival, then fixed tie-breaks.
10. **Raider (`punish`):** maximize `ownNetWorth − bestRivalNetWorth` (hurt rivals / grow lead); ties → lower best-rival worth, then fixed tie-breaks.
11. **Mixed (`balanced`):** score = `0.5 * wealthScore + 0.5 * punishScore` (normalized the same way in plan).
12. Tie-breaks fully specified in the plan (stable card id / company order / intent preference) so same state + strategy + RNG seed ⇒ same play.
13. AI must **not** use knowledge of the ordered draw pile beyond what a human sees (pile count only). Lookahead over unknown draws uses only public information (e.g. treat Draw as a coarse option vs evaluating concrete Trade plans).

### UI

14. Setup controls for controller, strategy, and rounds.
15. Collapsible **action log** at the bottom: append human and AI actions (draw/trade/play/choice/buy/sell/end turn, round advances, game over) so players can review what happened.
16. AI seats auto-advance; optional short delay so the board/log update is perceptible (may be longer when the AI emits several trade intents).

## Non-functional requirements

- Browser-only; AI client-side
- Strategy modules unit-testable without the DOM
- Recycle + rounds covered by engine tests
- AI decisions must not freeze the UI on a laptop (bound branching / depth)

## Acceptance checklist

- [ ] Setup: each seat human/AI + strategy; rounds 1–50 (default 10)
- [ ] Played cards re-insert at a random draw-pile index; Risks and hand Actions included
- [ ] Game ends after N full table cycles; ranking shown
- [ ] Mixed or all-AI games complete without input on AI seats
- [ ] Investor / Raider / Mixed behave per objectives (tests + spot-check)
- [ ] Seeded determinism test for AI intents
- [ ] Collapsible action log shows a readable trail of plays
- [ ] Tests for recycle, rounds end, and strategies pass
- [ ] Demo notes (`npm run dev`: 1 human + 1 AI, short rounds)
