## Summary

Add rounds-based game length with random re-insert of played cards into the draw pile; extend setup for per-seat human/AI + strategy; implement three deterministic AI policies (Investor / Raider / Mixed) that issue the same intents as humans; wire auto-play and a collapsible action log. Update digital rules text to match recycle + rounds.

## Approach

- Keep the pure `reduce(state, intent)` engine; extend state for rounds, seat controllers, and log events (or derive log entries at the UI/controller layer from successful reduces — prefer appending structured `GameLogEntry[]` on successful intents inside the engine or a thin wrapper so AI and UI share one trail).
- Recycle: replace `discardPile.push` with `insertAtRandom(drawPile, card, rng)`.
- End condition: stop using empty-pile game over as the primary end; end when completed full-table rounds hit `roundsTotal`.
- AI: `chooseIntent(state, strategy) → Intent` (call repeatedly until the seat’s turn advances or game over). Score legal candidates with bounded lookahead; no draw-pile peeking.
- UI: setup fields; when current player is AI, effect/timer applies intents; log panel collapsible at bottom.

## Strategy scoring (normative)

Let `W(i)` = net worth of player `i`, `self` = current AI index, `rival = argmax_{j≠self} W(j)`.

| Strategy | Score to maximize |
| --- | --- |
| Investor (`wealth`) | `W(self)`; tie → `W(self) - W(rival)` |
| Raider (`punish`) | `W(self) - W(rival)`; tie → `-W(rival)`; then `W(self)` |
| Mixed (`balanced`) | `0.5 * W(self) + 0.5 * (W(self) - W(rival))` ≡ `W(self) - 0.5 * W(rival)` |

**Lookahead (bounded):**

1. **`chooseHandCard` / `chooseCompany`:** for each legal card (± each `[?]` choice), simulate `reduce`, score resulting state. No further hidden draws.
2. **`optionalTrade`:** greedy multi-step: repeatedly pick the single legal `{buy\|sell, company, qty}` that most improves the strategy score (qty candidates: 1, floor(maxAffordable/2), maxAffordable for buy; 1, floor(held/2), held for sell), until no improving trade remains or a small step cap (e.g. 12) is hit, then `endTrade`. Deterministic order of companies = `COMPANIES` array order when scores tie.
3. **`chooseTurn`:** compare (a) best trade-only plan score vs (b) a **Draw** option scored without revealing the pile — use a conservative public heuristic: prefer Draw when hand has no positive Investor/Raider card play vs current market, else prefer the better of Trade vs “play best current hand card without drawing” only if already 5 cards… Actually hand is 4 until draw. Simpler rule: score **Trade** via (2); score **Draw** as the **average** strategy score over playing each current hand card after a hypothetical +1 unknown action that is ignored (i.e. evaluate best play among the **current 4** cards as a lower bound) **or** simply: if best hand-card play (on current 4) beats best trade plan, choose Draw only when pile length > 0 and best-of-current-hand exceeds trade — Wait, Draw adds a 5th card. Honest non-cheating approach: **Draw** score = max score obtainable by playing any of the current 4 cards (ignore unknown 5th); **Trade** = trade plan score; pick higher. Prefer Draw on tie if pile non-empty (fixed tie-break).

**Global tie-breaks** when scores equal: prefer intents in order `endTrade` < `sell` < `buy` < `chooseCompany` < `playCard` < `startTrade` < `draw`; then lower `cardId`; then company order in `COMPANIES`.
