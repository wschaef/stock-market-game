# Feature requirements: v0.6-finite-deck

**Status:** agreed  
**Owner:** Waldemar  
**Date:** 2026-08-20  

## Goal

Restore finite-deck play: played cards leave the draw pile permanently, the game ends when the draw pile is empty (not after a round limit), and setup lets players choose how many Risk and other (Action) cards go into the pile, with defaults that scale by seat count.

## In scope

- Stop recycling played cards into the draw pile; send them to the discard pile instead
- End the game when the draw pile is empty (remove round-limit end condition)
- Remove rounds from setup UI, engine config, HUD, and rules text
- Add start-menu fields: **Risk cards** and **Other cards** (Action cards in the draw pile)
- Meaningful defaults that depend on player count
- Update `docs/game-rules.md` Digital rules to match
- Engine, setup UI, tests

## Out of scope

- Changing card effect values or catalog composition
- Changing hand size, starting cash, or turn choices (Draw / Trade only)
- Online multiplayer
- New card types

## Users / context

Hotseat players configuring a game on the start screen, then playing until the pile runs out.

## Functional requirements

### A. No card recycle

1. When an Action or Risk card is fully resolved (played), it is **not** inserted back into the draw pile.
2. Resolved cards go onto the **discard pile** (append order is fine; discard is not reshuffled during play).
3. Cards remaining in players’ hands at game end stay in hand (not moved to discard unless already played).

### B. Game end = empty draw pile

1. Remove `roundsTotal` / `roundsCompleted` / round constants from the product surface (setup, state used for end checks, HUD “Round x / y”, start log that mentions rounds).
2. The game **does not** end after a fixed number of table rounds.
3. **End timing:** when the draw pile becomes empty, the **current player finishes their turn** (play the drawn Action, or finish optional trade after a Risk / Trade-only). On the subsequent turn advance, if the draw pile is empty, phase becomes `gameOver` and scoring runs as today.
4. Consequence: with an empty pile, players cannot keep taking Trade-only turns forever — the match ends after the turn that emptied the pile (or immediately on advance if the pile is already empty).
5. Draw remains illegal when the pile is empty (unchanged fail-fast during the emptying turn).

### C. Setup: Risk cards & Other cards

1. On the start menu (alongside player seats), expose two integer fields:
   - **Risk cards** — count of Risk cards shuffled into the draw pile
   - **Other cards** — count of Action cards (standard, +100, multiplier) shuffled into the draw pile
2. Remove the **Rounds** field entirely.
3. **Defaults by player count** `n` (same ratios as today’s fixed per-player mix, capped by catalog leftovers after dealing hands):

   | Players `n` | Default Risk | Default Other | Notes |
   | ---: | ---: | ---: | --- |
   | 2 | 6 | 18 | `3n` / `9n` |
   | 3 | 9 | 27 | `3n` / `9n` |
   | 4 | 12 | 32 | Risk `3n`; Other capped at leftover Actions after `4n` hands (48 − 16 = 32), not 36 |

4. When the player-count control changes, reset Risk/Other fields to the defaults for the new `n` (so defaults stay meaningful).
5. **Validation (fail fast on Start):**
   - Both counts are integers ≥ 0
   - `risk + other ≥ 1` (non-empty starting pile)
   - `risk ≤` available Risk catalog size (15)
   - `other ≤` Action cards left after dealing starting hands (`48 − 4n`)
6. Setup builds the pile by taking exactly those counts from shuffled catalogs; leftovers stay in `unusedCards`.

### D. Rules / copy

1. Digital rules in `docs/game-rules.md`: replace round limit + recycle with empty-pile end + discard; document configurable pile counts and defaults.
2. In-game chrome: drop round display; keep pile size visible.

## Non-functional requirements

- Deterministic engine behavior remains testable with injected `random` / shuffle
- TDD: failing tests for no-recycle, empty-pile end, and setup defaults/validation before production code changes

## Acceptance checklist

- [x] Playing a card never increases draw-pile size; card appears on discard instead
- [x] Game reaches `gameOver` when the draw pile is empty after the emptying turn completes — not after N rounds
- [x] Start menu has Risk cards + Other cards; no Rounds control
- [x] Changing player count resets Risk/Other to the table above
- [x] Invalid counts are rejected with clear errors; valid counts match pile composition
- [x] `docs/game-rules.md` Digital section matches this behavior
- [x] Tests covering the behaviors above exist and pass
- [x] Demo / verification: start with small pile, play until empty, confirm end + scores

## Open questions

None blocking — end-after-current-turn (vs hard-stop mid-trade) is specified in §B.3. Say if you prefer ending the instant the last card leaves the pile (skipping remaining optional trade).
