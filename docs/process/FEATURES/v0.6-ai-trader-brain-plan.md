# Implementation plan: v0.6-ai-trader-brain

**Status:** approved  
**Requirements:** `docs/process/FEATURES/v0.6-ai-trader-brain-requirements.md` (agreed)  
**Date:** 2026-08-20  

## Summary

Replace Investor/Raider/Mixed net-worth-only scoring with one shared trader brain. Score each candidate state as a weighted mix of wealth, lead, **chance** (potential), and **risk**. Three profiles — Aggressive / Middle / Defensive — differ only by weights. Soft penalties only (no hard trade caps). Update types, setup defaults, UI labels, rules blurb, and engine tests (TDD).

## Approach

- Keep `chooseIntent` / bounded lookahead / trade qty candidates / tie-breaks as in v0.3; swap the **score** under the hood.
- Evaluate features on the **resulting** `GameState` after each simulated intent (same pattern as today’s `strategyScoreVector`).
- Dollar-ish features (not 0–1) so weights stay interpretable.
- Soft-only: risk/chance terms steer behavior; no hard “never buy below 30” rules unless a fixture cannot be satisfied otherwise (then document a minimal cap in a follow-up — not this plan’s default).
- Rename strategy ids in one pass; no legacy aliases.

### Score (normative)

Let `W` = `netWorth(self)`, `rival` = best rival net worth, `lead = W − rival`.

```text
score = wW * W + wL * lead + wC * chance − wR * risk
```

Profiles use a **scalar** score (higher better). Existing intent tie-breaks apply when scores are equal (`INTENT_PREF`, card id, company order, qty).

### Hand upside `U(C)`

For each company `C`, from the AI’s current hand only (public to that seat):

- For each hand card, simulate play + best `[?]` assignments that **maximize** resulting price of `C` (bounded choice search, same as today’s `scoreThroughChoices` style).
- `U(C) = max(0, best Δprice(C) over those cards)` after split/wipeout rules.
- If the hand is empty, `U(C) = 0`.

No peeking at the draw pile.

### Chance (potential)

For each company `C` with price `p = max(prices[C], 1)`, self shares `s`, best-rival shares `r`:

| Term | Formula | Intent |
| --- | --- | --- |
| Holding synergy | `0.3 * s * U(C)` | cards move your book (scaled so option value does not drown realized wealth) |
| Share-lead synergy | `max(0, s − r) * U(C)` | prefer leading where you can pump |
| Leverage / entry | `(cash / p) * U(C) * 0.2` | low `p` → more shares per dollar for the same card (the ×4 idea); muted so it does not force all-cash “phantom” chance alone |

```text
chance = Σ_C ( 0.3*s*U(C) + max(0,s−r)*U(C) + [entry] (cash/p)*U(C)*0.2 )
```

The **entry** term is included when scoring trade plans / buy-sell intents. It is **omitted** when scoring card plays / `[?]` choices so deferred pumps do not beat an immediately better play.

Idle cash with **no** hand upside stays low chance → Trade to deploy into hand-strong names beats empty Draw loops.

### Risk (fragility)

Wipeout band heat for price `p` (legal wipeout at `< 10`):

```text
heat(p) = clamp( (40 − p) / 30 , 0 , 1 )     // 0 at p≥40; 1 at p≤10
```

Per company position value `v = s * prices[C]`:

| Term | Formula | Intent |
| --- | --- | --- |
| Wipeout exposure | `v * heat(p) * (U(C) > 0 ? 0.55 : 1.0)` | low price hurts more without supportive cards (“orphan”) |
| Concentration | `0.35 * W * (max_C v / max(W,1))^2` | once | penalize single-name all-in |
| Cash starvation | `max(0, 0.08*W − cash) * 2` | keep a small rebuild buffer |

```text
risk = Σ_C wipeoutExposure(C) + concentration + cashStarvation
```

### Weights (initial — tune only if a listed fixture fails)

| Weight | Aggressive | Middle | Defensive |
| --- | ---: | ---: | ---: |
| `wW` | 1.0 | 1.0 | 1.0 |
| `wL` | 0.85 | 0.40 | 0 |
| `wC` | 1.15 | 0.85 | 0.50 |
| `wR` | 0.40 | 0.95 | 1.55 |

Personality check: Aggressive leans chance + lead; Defensive leans risk; Middle is the risk-vs-potential seat.

### Lookahead (unchanged shape)

1. **Hand / company:** simulate card (± choices), score resulting state.
2. **Trade:** greedy multi-step with qty candidates `{1, ⌊max/2⌋, max}`, step cap 12; pick improving trades by **new score**; end when none improve.
3. **Choose turn:** Trade plan score vs Draw scored as best play among **current** hand cards (no pile peek). Prefer Trade when undeployed cash + hand upside make the trade plan win (fixtures assert this).

Neutral wealth-only buys no longer need a special case: chance/risk should make sensible buys **improving**. Keep a safety: if somehow only wealth-neutral buys exist and score ties endTrade, existing buy tie-break may still fire — fixtures must ensure we do not all-in junk; if they fail, drop the old “always take neutral buy” preference and only buy when `score(buy) > score(endTrade)`.
