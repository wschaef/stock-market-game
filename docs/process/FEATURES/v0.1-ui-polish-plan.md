# Implementation plan: v0.1-ui-polish

**Status:** approved  
**Requirements:** `docs/process/FEATURES/v0.1-ui-polish-requirements.md` (agreed)  
**Date:** 2026-08-15  

## Summary

Polish the hotseat React UI so the current player, their hand, relative market prices, and per-share buy/sell are obvious. No engine rule changes; add a small pure helper for relative bar widths and restyle the board.

## Approach

- Pure `relativeBarPercents(prices)` helper (TDD) for diagram widths
- Keep `reduce` / phases unchanged; UI only rearranges presentation
- Hand always rendered for the current player; clickable only in `chooseHandCard`
- Market section becomes a relative bar diagram with inline Buy/Sell when `canTrade`
- Distinct turn banner naming the active player

## Steps

1. Add `relativeBarPercents` + unit test.
2. Redesign `App.tsx` layout: turn banner, market diagram with trade controls, always-visible hand, phase actions.
3. Restyle `index.css` (+ fonts in `index.html`) for clearer hierarchy and light motion.
4. Run lint and tests; demo locally.
