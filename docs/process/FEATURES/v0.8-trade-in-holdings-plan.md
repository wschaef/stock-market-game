# Implementation plan: v0.8-trade-in-holdings

**Status:** approved  
**Requirements:** `docs/process/FEATURES/v0.8-trade-in-holdings-requirements.md` (**agreed**)  
**Date:** 2026-10-01  

## Summary

Fold the existing Trade strip into the Holdings panel. While a human can trade, Buy/Sell appear under share counts on the **on-turn player row**; quantity + End turn sit in a toolbar inside Holdings. Delete the standalone `TradeStrip` board section and its grid CSS slot.

## Approach

- Pass trade props into `Scoreboard` when `trading` is true: `qty`, `setQty`, `onBuy`, `onSell`, `onEndTrade`.
- In the on-turn player’s company cells, render Buy above and Sell below the share count.
- Keep quantity + End turn as a compact toolbar under the table (still inside Holdings).
- Remove `TradeStrip` usage from `Board`; delete the component.
- CSS: compact stacked buttons in holdings cells; drop `.trade-strip-panel` board-grid rules.

## Steps

1. Extend Holdings/`Scoreboard` to render on-turn cell controls + toolbar when trading.
2. Wire props from `Board`; remove separate `TradeStrip` render.
3. Update CSS; remove obsolete trade-strip panel layout.
4. Manual check: start trade → buy/sell from on-turn row → end turn; confirm non-trade Holdings unchanged.
