# Feature requirements: v0.4-hidden-hands-motion

**Status:** agreed  
**Owner:** Waldemar  
**Date:** 2026-08-17  

## Goal

Keep unplayed hands private so a player sees **only their own cards**, slow AI auto-play so each move is easier to follow, and animate board changes (prices, money, shares, cards, turn) so updates are perceptible.

## In scope

- Hide other seats’ unplayed hand faces (AI and other humans)
- Do not leak a drawn **Action** title to anyone except the owner (Risks stay public)
- Action log must not name an Action that was only drawn into a hidden hand
- Increase AI step delays so moves are a bit slower than today
- CSS/React motion for price bars, cash/wealth/share/price numbers, hand cards, and turn changes
- Share-price tiles that moved **this play** (from `lastEvents`) use a different brightness than the rest of the bar
- Respect `prefers-reduced-motion` (already global; keep it)

## Out of scope

- Online multiplayer, accounts, persistence
- Changing AI strategy logic, card catalog, or engine scoring
- Animating every individual price-bar tick as a unique sprite
- Peeking / “reveal all” debug cheat
- Redesigning layout beyond privacy + motion

## Users / context

Solo and mixed human/AI games on one device. Humans should not read AI (or other) hands. Hotseat with several humans still shows the **current human’s** cards on the shared device.

## Decisions (locked)

| Topic | Decision |
| --- | --- |
| Viewer | **One human** in the game → always show that human’s hand. **Several humans** (hotseat) → show the current human’s hand only. **All AI** → face-down backs for the seat on turn. |
| Drawn Action | Private until played. UI may say an Action was drawn; it must not show the title/face. Log line must not include the Action title. |
| Drawn Risk | Public (resolved immediately); title and effects stay visible. |
| Played cards | Public (log + events), including AI plays. |
| AI pace | Roughly **1.6–1.8×** current delays (think / draw / play / trade). Still scales a bit by intent type. |
| Motion | Flash numbers on change; ease price-bar fills; **brighter tiles for a rise, dimmer for a fall** on this play; deal-in cards; replay turn-banner enter when the seat changes. |

## Functional requirements

1. The hand panel never shows another seat’s card faces. The local viewer sees only their own faces (or face-down backs when there is no local human viewer).
2. Hover wealth preview stays only for the viewer’s playable cards.
3. `lastDrawn` Action titles are shown only to the owning human; other viewers get a generic “Action drawn” (or nothing). Risks still show the title.
4. Engine log for an Action draw does **not** include the card title. Play, Risk resolve, and `[?]` choice lines stay specific.
5. AI auto-play waits longer between intents than the previous 280/450/550/650/700 ms set.
6. When prices, cash, wealth, or share counts change, the UI animates the change. New/updated hand cards animate in. The turn banner animates when the current seat changes.
7. Share-price bar tiles that filled or emptied on the latest card (`lastEvents`) use a different brightness than unchanged tiles.

## Non-functional requirements

- Browser-only; no new dependencies
- Visibility and pacing helpers unit-testable without the DOM
- Keep the rules engine free of CSS; log privacy is an engine text change

## Acceptance checklist

- [ ] Mixed game (1 human + AI): human never sees AI card faces; still sees their own hand during AI turns
- [ ] Hotseat (2+ humans): only the current human’s faces are shown
- [ ] Drawn Action title is not shown in the banner or log until the card is played
- [ ] Drawn Risk title remains visible
- [ ] AI moves are noticeably slower than before (spot-check)
- [ ] Price / wealth / share / card / turn updates animate (spot-check; reduced-motion still disables)
- [ ] Tiles that moved on the latest price change are brighter (rise) or dimmer (fall)
- [ ] Tests for viewer/hand presentation, log privacy, and AI delay mapping pass
- [ ] Demo notes (`npm run dev`: 1 human + 1 AI)
