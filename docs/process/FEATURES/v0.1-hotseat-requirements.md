# Feature requirements: v0.1-hotseat

**Status:** agreed  
**Owner:** Waldemar  
**Date:** 2026-08-15  

## Goal

A playable browser hotseat of Börsenspiel: 2–4 players on one device, real card catalog, digital split/wipeout rules, end-of-game net worth ranking. Deployed as a static site on GitHub Pages.

## In scope

- Local hotseat, 2–4 named players
- Full 63-card catalog from `docs/game-rules.md`
- Turn loop: Draw or Trade only
- No trading after playing a non-Risk Action (core rule)
- Optional trade after a Risk card
- `[?]` = current player picks one of the other three companies
- Split when target price > 250; wipeout when target price < 10
- Game end when the draw pile is empty (after resolving that last card)
- GitHub Pages deploy

## Out of scope

- Online multiplayer, accounts, persistence
- AI opponents
- Native apps, live market data, tutorials beyond on-screen card text

## Users / context

People learning the stock-market table game on a shared laptop or phone browser.

## Functional requirements

1. Setup: prices 100; each player $1,000 and 4 Action cards; draw pile = 6 Action + 3 Risk per player, shuffled; leftover cards unused.
2. Action cards = Standard, +100, and Multiplier. Risk cards are only in the pile mix.
3. Draw reveals the top card. Action → hand, then must play 1 of 5. Risk → apply immediately, then optional buy/sell.
4. Trade-only turn: buy and/or sell at current prices; no draw. After a non-Risk play, trade is not offered.
5. Bank: 40 shares per company at start. Cannot overspend, oversell, or buy more than the bank holds. After splits, player totals may exceed 40.
6. Split: if target > 250, price = floor(target / 2) and each shareholder’s shares of that company double (bank leftovers do not). Repeat until price ≤ 250. 250 is legal.
7. Wipeout: if target < 10, all player shares of that company are lost (no cash), bank resets to 40, price resets to 100. 10 is legal.
8. Effects apply per company independently. Omitted risk companies are +0. Halve uses floor, then split/wipeout checks.
9. End: finish resolving the emptying draw (including optional post-Risk trade), then score `sum(shares[c] * price[c]) + cash`. Highest wins; ties allowed.
10. UI shows market, whose turn, card text, `[?]` picker, trade only when the phase allows it, split/wipeout, and final ranking.

## Non-functional requirements

- Browser-only, no backend
- Static GitHub Pages deploy
- Rules engine testable without the DOM

## Acceptance checklist

Human reviews these outcomes (not code by default):

- [ ] 2–4 players can start a hotseat game
- [ ] Draw vs Trade-only works; Action play does not allow a trade
- [ ] Risk play allows an optional trade
- [ ] `[?]` lets the player pick another company
- [ ] Split (>250) halves target price and doubles shareholder shares
- [ ] Wipeout (<10) destroys holdings and resets price to 100
- [ ] Empty pile ends the game with a net-worth ranking
- [ ] Tests covering the behaviors above exist and pass
- [ ] Demo via `npm run dev` and/or GitHub Pages
