# Implementation plan: v0.4-hidden-hands-motion

**Status:** approved  
**Requirements:** `docs/process/FEATURES/v0.4-hidden-hands-motion-requirements.md` (agreed)  
**Date:** 2026-08-17  

## Summary

Stop showing other seats’ unplayed cards, stop leaking drawn Action titles in the log/banner, lengthen AI auto-play delays, and add light CSS/React animations when the board updates. Engine rules stay the same except Action-draw log wording.

## Approach

- Pure UI helpers decide **who** may see a hand and whether `lastDrawn` is public.
- Hand panel binds to that presentation: face-up for the local viewer, face-down backs otherwise.
- Engine: Action-draw log line omits the card title; Risk and play lines stay specific.
- Export AI delay constants (~1.6–1.8× current) and use them in the existing `setTimeout` loop.
- Motion via CSS (bar fills, card deal-in, number flash) plus remounting the turn banner on seat change. Honor existing `prefers-reduced-motion` reset.

## Steps

1. TDD: `viewingSeatIndex` / `handPresentation` / `lastDrawnAnnouncement` for one-human, hotseat, all-AI, Action vs Risk.
2. TDD: Action draw log has no card title; Risk resolve and play still name the card.
3. TDD: `aiDelayMs` maps intents to the new slower constants.
4. Wire `App.tsx` hand, last-drawn banner, and AI timeouts to the helpers.
5. Add flash-on-change for prices, cash, wealth, share counts; CSS for bars and card backs; `key` on turn banner.
6. One digital-rules bullet: other hands stay hidden; drawn Actions are private until played.
