# ADR: v0.1-web-pages

**Status:** accepted  
**Date:** 2026-08-15  
**Related requirements:** `docs/process/FEATURES/v0.1-hotseat-requirements.md`

## Context

Slice 1 is a local hotseat prototype with no accounts, no live data, and a GitHub Pages deploy target. The rules must be unit-testable (TDD) independently of UI.

## Decision

- Vite + TypeScript + React for the browser UI
- Vitest for tests
- Pure TypeScript rules engine (no DOM)
- Card catalog as data
- Static `vite build` published to GitHub Pages (`base` compatible with project Pages)
- No server, no database

## Alternatives considered

| Option | Fit | Cost / complexity | When it breaks |
| --- | --- | --- | --- |
| A. Static Vite SPA (chosen) | Hotseat + Pages | Low | Online multiplayer |
| B. Backend + WebSockets | Online play | High for v0.1 | Overkill now |
| C. Desktop/native | Installable | Extra toolchain | Pages deploy |

## Consequences

- Positive: simple CI, TDD on the engine, Pages hosting
- Negative / tradeoffs: all players share one device; refresh loses the game
- Deferred: networking, AI, persistence
